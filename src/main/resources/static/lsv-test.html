Prueba LSV (lengua de señas)

Si el reproductor muestra tiempo (ej. 0:03) pero la imagen es negra, el archivo suele ser H.265 / HEVC. Los navegadores web suelen necesitar H.264.

Archivo para la web (sin paréntesis en la URL):

Solución: ejecute scripts\reencode-lsv-a-h264.bat en la raíz del proyecto, o en videos/lsv/ ejecute (necesita ffmpeg):

ffmpeg -y -i "0409(2).mp4" -c:v libx264 -profile:v main -pix_fmt yuv420p -movflags +faststart -an "0409-2.mp4"

Eso sustituye 0409-2.mp4 por una copia en H.264. Reinicie Spring y recargue con Ctrl+F5.
